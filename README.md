# AWS CLF-C02 Practice Exam

Timed practice exam for AWS Certified Cloud Practitioner (CLF-C02): 65 questions, 90 minutes, multiple choice and multiple response.

Questions come from [nastaso/cloudcertprep](https://github.com/nastaso/cloudcertprep) (MIT). They are original practice items, not official AWS exam dumps.

```bash
npm install
npm run dev
```
